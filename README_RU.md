# Vistarel — быстрый современный просмотрщик изображений для Windows

**Vistarel — быстрый и лёгкий нативный просмотрщик изображений для Windows 10/11 с инструментами сравнения, пакетной обработки, увеличения и анализа цвета.**

Vistarel построен вокруг простого рабочего процесса:

**открыть → изучить → сравнить → обработать → продолжить работу в Photoshop или другом приложении**

**Бесплатно · Windows 10/11 · x64 · Русский и English · Регистрация не требуется**

[**Скачать Vistarel 1.1**](https://github.com/tempchar01/Vistarel/releases/latest) · [**Поддержать Vistarel ♥**](https://app.lava.top/tempchar)

---

## Просмотр изображений

Быстрый просмотр изображений с навигацией по папке, миниатюрами, режимами Fit/100%, масштабированием, панорамированием, поворотом и полноэкранным режимом.

![Vistarel Viewer](viewer.jpg)

## Детальный просмотр

Используйте встроенную лупу и инструменты анализа цвета, не покидая просмотрщик.

![Vistarel Magnifier](magnifier.jpg)

## Сравнение

Сравнивайте два изображения рядом с синхронизированным просмотром и инструментами выравнивания.

![Vistarel Smart Compare](compare.jpg)

## Пакетная обработка

Обрабатывайте сразу несколько файлов: кадрирование, поворот и отражение, изменение размера, конвертация и переименование.

![Vistarel Batch Processing](batch.jpg)

## Информация о файле

Просматривайте основные сведения об изображении: размеры, размер файла, глубину цвета, разрешение и цветовой профиль.

![Vistarel File Information](info.jpg)

## Поддерживаемые форматы изображений

Текущая версия для Windows поддерживает распространённые форматы через встроенную среду обработки изображений, включая:

**JPEG · PNG · WebP · TIFF · BMP · GIF · ICO**

Доступность экспорта зависит от выбранного выходного формата и кодеков, включённых в поставку.
